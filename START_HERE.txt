⚡ DÉMARRAGE EN 1 MINUTE
═══════════════════════════════════════════════════════════════════════════

  1. Installez:
     $ cd interface
     $ python3 -m venv venv
     $ source venv/bin/activate
     $ pip install -r requirements.txt

  2. Lancez:
     $ python main.py

  3. Cliquez sur "📍 Localité" dans la toolbar, puis sur le canvas
  
  ✅ Vous venez de créer votre première localité !

🎯 FONCTIONNALITÉS PRINCIPALES
═══════════════════════════════════════════════════════════════════════════

  ✓ Créer des localités (états) automatiquement numérotées (l0, l1, l2...)
  ✓ Créer des transitions (flèches) entre localités
  ✓ Déclarer des horloges (x, y, z...)
  ✓ Ajouter des invariants (x <= 5)
  ✓ Ajouter des gardes (x > 3)
  ✓ Ajouter des resets (x := 0)
  ✓ Sauvegarder/charger au format JSON
  ✓ Débogage en direct (Cmd+D)

🚀 EXEMPLE COMPLET (3 minutes)
═══════════════════════════════════════════════════════════════════════════

  Créer un automate "feu tricolore":
  
  1. Mode: Cliquez "📍 Localité"
  2. Canvas: Cliquez 3 fois → l0, l1, l2 s'ajoutent
  3. Mode: Cliquez "➔ Transition"
  4. Canvas: l0 → l1, l1 → l2, l2 → l0
  5. Ajouter horloge "t" via Menu → Déclarer Horloges
  6. Chaque transition: +Garde "t > 5", +Reset "t"
  7. Menu → Sauvegarder
  
  ✅ Automate à 3 états avec timing !

🐛 PROBLÈME ?
═══════════════════════════════════════════════════════════════════════════

  "L'app ne démarre pas"
  → pip install PySide6

  "Aucun clic enregistré"
  → Vérifiez que le mode est activé (bouton surligné)
  → Essayez Échap puis réactivez

  "JSON invalide"
  → Vérifiez que c'est un fichier créé par cet outil
  → Utilisez model_template.json comme référence

  Voir: README.md → Troubleshooting
