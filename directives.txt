Pour que ta "pieuvre" fonctionne sans s'emmêler les tentacules, voici le protocole exact à suivre dès qu'une nouvelle localité est créée. On sépare l'existence logique (le Buffer) de l'apparence visuelle (la Scène).
Le flux de création (Step-by-Step)

    L'utilisateur clique sur le QToolButton "+ Nouvelle Localité".

    La Vue émet un signal vers le Contrôleur.

    Le Contrôleur génère un ID unique et définit les coordonnées par défaut.

    Le Contrôleur enregistre ces données dans le Buffer du Modèle.

    Le Contrôleur ordonne à la Vue de dessiner le cercle.
